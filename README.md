## My Contributions – Document Intelligence Layer

As a member of Team Prime Bug, I contributed to the development of the Document Intelligence module of **BidSure AI**, an AI-powered bid compliance verification platform for GeM procurement.

### Work Completed

- **Document Loading & Processing:** Developed document-loading and extraction functionality for PDF and image-based documents.
- **OCR Integration:** Worked on extracting machine-readable text from scanned documents.
- **Document Classification:** Implemented document classification to identify document types.
- **Confidence Scoring:** Improved confidence scoring to assess the reliability of extracted information.
- **Ambiguity Detection:** Added ambiguity detection to identify uncertain or unclear extracted information.
- **Data Extraction:** Worked on extracting structured information from bidder documents.
- **Testing:** Created and executed Pytest test cases to validate document processing, classification and extraction functionality.
- **Backend Integration:** Contributed to the Document Intelligence service architecture and its integration with the backend.

### Technologies Used

Python | FastAPI | OCR | Pytest | PDF Processing | NLP | Git & GitHub

### Key Contribution

My primary focus was developing a reliable Document Intelligence pipeline that converts unstructured bidder documents into structured information that can be used by the Compliance Engine for further evaluation.
